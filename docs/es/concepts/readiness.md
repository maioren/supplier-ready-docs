# Readiness

**Readiness** representa cuánto está preparada su empresa para avanzar con un cliente según los requisitos conocidos y el estado real de cada uno.

Readiness no debe ser una suposición de la IA. El mismo estado de requisitos debe producir el mismo resultado.

## Ready

Estar **Ready** significa saber qué se aplica, qué ya se resolvió, qué todavía necesita acción y qué depende de una aclaración — y resolver todo lo que impide avanzar.
