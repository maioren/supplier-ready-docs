# Su primer análisis

!!! info "En desarrollo"
    Esta página describe la experiencia que estamos construyendo y se actualizará a medida que el flujo completo esté disponible.

Un análisis comienza con los requisitos recibidos de su cliente.

## 1. Traiga la fuente

Proporcione el texto o documento recibido. Supplier Ready trata la fuente original como evidencia de lo que realmente fue solicitado.

## 2. Revise los requisitos identificados

Los requisitos se organizan en elementos individuales y trazables.

## 3. Aclare la incertidumbre

Cuando una conclusión no pueda sustentarse de forma segura en la fuente, la duda permanece visible en lugar de convertirse en una suposición.

## 4. Compare con su empresa

A partir de los requisitos, el producto podrá mostrar qué ya está cumplido, qué necesita acción y qué todavía depende de aclaración.

## 5. Llegue a Ready

El objetivo es transformar los requisitos en un camino claro para que su empresa avance con el nuevo cliente.
