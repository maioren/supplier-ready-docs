# Supplier Ready Docs

Public product documentation for **Supplier Ready**.

The product source code lives in a separate private repository. This repository contains only public-facing product documentation and the GitHub Pages publishing setup.

Documentation is published in Brazilian Portuguese, English, and Spanish, with **PT-BR as the editorial source of truth**.

## Documentation Definition of Done

A product or documentation change is not considered documentation-complete until:

1. the implemented behavior has been reflected in PT-BR;
2. the PT-BR wording has been factually and editorially reviewed;
3. the same meaning and contract have been synchronized to EN and ES;
4. navigation and cross-links remain valid in all three languages;
5. Reference documents only implemented contracts, while future intent remains in Product/roadmap content.

Translations do not need to be literal, but PT-BR, EN, and ES must describe the same product state and public contract.
